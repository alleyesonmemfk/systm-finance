# SYSTM Финансы — сборки для macOS

Личные финансы: счета, операции, категории, платежи. Данные лежат на вашем Mac в обычных файлах, облака нет. Здесь только готовые версии, последняя — в [Releases](https://github.com/alleyesonmemfk/systm-finance/releases/latest).

## Установка (один раз)

1. Скачайте `SYSTM-Finance_<версия>_universal.dmg` из [последнего релиза](https://github.com/alleyesonmemfk/systm-finance/releases/latest) и перетащите «SYSTM Финансы» в «Программы».
2. Первый запуск: macOS скажет, что не может проверить разработчика. Откройте «Системные настройки → Конфиденциальность и безопасность» и внизу нажмите «Всё равно открыть».
3. На экране приветствия нажмите «Начать» — данные будут в «Документы / SYSTM Финансы».

Дальше приложение обновляется само: при запуске оно проверяет новую версию и предлагает «Обновить» — скачивает её, сверяет подпись и перезапускается. Данные остаются в своей папке.
